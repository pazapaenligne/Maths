Les nombres relatifs un nombre + un signe ( + ou − )
➕➖ 1. Qu’est-ce qu’un nombre relatif ? +

Un nombre relatif est formé d’un nombre (la partie numérique) précédé d’un signe :

• le signe + pour les nombres positifs ;
• le signe − pour les nombres négatifs.

Le nombre 0 n’est ni positif ni négatif.

Exemples +5 (positif) · −3 (négatif) · +2,7 · −7,44
📏 2. L’axe gradué (la droite des nombres) +

On range les nombres relatifs sur une droite graduée. L’origine est le point 0.

• À droite de 0 → les positifs (ils grandissent vers la droite).
• À gauche de 0 → les négatifs.

📍 3. Repérer un point : l’abscisse +

Sur la droite graduée, chaque point est repéré par un nombre relatif appelé son abscisse.

On écrit par exemple A(−3) : le point A a pour abscisse −3, il est donc à gauche de 0.

À lire A(−3) → 3 graduations à gauche de 0
B(+2) → 2 graduations à droite de 0
🔁 4. Nombres opposés +

Deux nombres sont opposés s’ils ont la même partie numérique mais des signes contraires.

Sur l’axe, ils sont à la même distance de 0, de part et d’autre.

Exemples L’opposé de +5 est −5
L’opposé de −2,7 est +2,7
📐 5. Distance à zéro +

La distance à zéro d’un nombre relatif est sa partie numérique, sans son signe. Elle est toujours positive.

C’est l’écart entre le point et l’origine 0 sur l’axe.

Exemples Distance à zéro de −4 → 4
Distance à zéro de +4 → 4 (les opposés ont la même !)
