🌹 MISSION CUVE PERCÉE

Une catastrophe vient de se produire dans l’atelier de Colle & Sugar ! Une vanne défectueuse a provoqué une fuite lente mais constante sur une ligne de stockage de sirop de rose. Le bilan comptable affiche une perte sèche globale de −120 dinars pour ce lot. Tu sais que chaque bocal endommagé représente une perte unitaire de −15 dinars sur ta matière première. L’inventaire informatique ayant planté, tu dois diviser la perte totale par le coût unitaire pour déterminer combien de bocaux ont fui et doivent être jetés avant de relancer la production !

Division de nombres relatifs — l'essentiel

1. Définition : diviser a par b (avec b ≠ 0), c'est chercher le nombre c tel que b × c = a. Notation : a ÷ b = c ou a / b = c.

2. La règle des signes (identique à la multiplication) :
• (+) ÷ (+) = (+)
• (+) ÷ (−) = (−)
• (−) ÷ (+) = (−)
• (−) ÷ (−) = (+)

Astuce mémoire : signes identiques → +, signes différents → −. (La même règle qu'en multiplication !)

3. Méthode en 2 temps :
• Étape A : calculer le quotient des valeurs absolues (les « nombres sans signe »).
• Étape B : appliquer la règle des signes pour déterminer le signe du résultat.

4. Cas particuliers :
• Diviser par 0 : IMPOSSIBLE. On dit que la division par zéro n'est pas définie.
• Diviser par 1 : a ÷ 1 = a. Le nombre reste le même.
• Diviser par lui-même : a ÷ a = 1 (si a ≠ 0).
• 0 divisé par a (avec a ≠ 0) : 0 ÷ a = 0.

5. Vérification : pour vérifier qu'une division est juste, on multiplie le quotient par le diviseur. On doit retrouver le dividende.
Ex : si (−120) ÷ (−15) = 8, vérifions : (−15) × 8 = −120 ✓.

6. Application contextuelle : quand on cherche un nombre d'objets (bocaux, personnes, jours…), le résultat doit forcément être positif. Si on tombe sur un négatif, c'est qu'il y a une erreur quelque part dans le raisonnement.

Division de relatifs — les compétences du jour
➗Définition : a ÷ b = c signifie b × c = a. La division est l’opération inverse de la multiplication.
✕Règle des signes : identique à la multiplication. Mêmes signes → + ; signes différents → −.
🧮Méthode en 2 temps : calculer le quotient des valeurs absolues, puis appliquer la règle des signes.
✅Vérifier la division en repassant par la multiplication : si a ÷ b = c, alors b × c doit redonner a.
À retenir : en division comme en multiplication, mêmes signes → +, signes différents → −. On calcule d’abord le quotient des valeurs absolues, puis on place le bon signe. Attention : diviser par 0 est impossible.
