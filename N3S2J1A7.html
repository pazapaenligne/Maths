📚 Ce que je retiens

La fonction linéaire f : x ↦ ax

📝 La leçon
Définitions

Pour un nombre a donné, la fonction f qui associe à tout nombre x le nombre ax est une fonction linéaire. On écrit f : x ↦ ax.

Le nombre a est le coefficient de la fonction linéaire f.

Exemple : La fonction f : x ↦ 4x est une fonction linéaire de coefficient 4.
Propriété

Un tableau de valeurs d'une fonction linéaire est un tableau de proportionnalité.

Exemple : Pour la fonction f : x ↦ 4x, on considère le tableau de valeurs suivant :
x−3−101,52
f(x)−12−4068
× 4  (on multiplie chaque x par 4)

a = 4 est le coefficient de proportionnalité du tableau.

Remarque : Toute situation de proportionnalité peut être modélisée par une fonction linéaire.

📋 L'essentiel à retenir

1.Une fonction linéaire s'écrit f(x) = ax : on multiplie x par un nombre fixe a.
2.a est le coefficient de la fonction (et le coefficient de proportionnalité du tableau).
3.Le tableau de valeurs est un tableau de proportionnalité.
4.Toute situation de proportionnalité se modélise par une fonction linéaire.
