▶ DÉFI RÉVISION 3E
Les identités remarquables — l'essentiel

Trois formules à connaître par cœur :

1. (a + b)² = a² + 2ab + b²
Ex : (x + 3)² = x² + 6x + 9

2. (a − b)² = a² − 2ab + b²
Ex : (2x − 5)² = 4x² − 20x + 25

3. (a + b)(a − b) = a² − b²
Ex : x² − 25 = (x − 5)(x + 5)

Astuce : pour factoriser, repère la forme (a²−b² → différence de carrés, a²+2ab+b² → carré d'une somme).
