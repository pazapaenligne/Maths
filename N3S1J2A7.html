La bonne méthode pour résoudre une équation produit nul.

👉 Consigne : identifie la bonne méthode pour résoudre une équation produit nul, puis clique sur « Valider ».
Pour résoudre une équation produit nul de la forme (ax + b)(cx + d) = 0, on utilise la propriété du produit nul : si un produit est nul, alors au moins l'un des facteurs est nul. On résout donc séparément ax + b = 0 et cx + d = 0.
Pour résoudre une équation produit nul, il suffit de diviser les deux côtés par l'un des facteurs.
Pour résoudre une équation produit nul, on peut additionner les deux facteurs et résoudre l'équation obtenue.
💡 Si un produit est nul, alors au moins un des facteurs doit être nul. On ne peut pas diviser par un facteur qui pourrait être égal à zéro !

📌 À retenir :
Propriété du produit nul :
Si A × B = 0, alors A = 0 ou B = 0.

Pour résoudre (ax + b)(cx + d) = 0 :
➡ ax + b = 0 → x = −b/a
➡ cx + d = 0 → x = −d/c

L'équation a donc deux solutions (ou une seule si elles sont égales).
