Le calcul littéral

Évaluer, développer, réduire, factoriser : les quatre gestes du calcul avec des lettres.

🔢 Évaluer une expression

Remplacer les lettres par un nombre

Évaluer une expression, c'est remplacer les variables (les lettres) par leur valeur, puis calculer.

Exemple

Pour x = 3 : 2x + 5 = 2 × 3 + 5 = 11

📂 Développer

Supprimer les parenthèses

k(a + b) = ka + kbdistributivité
+(a + b) = a + ble + ne change rien
−(a + b) = −a − ble − change tous les signes
⚠️ Devant une parenthèse, le signe − change le signe de chaque terme : −(x + 4) = −x − 4 et −(3x − 2) = −3x + 2.
🧹 Réduire

Écrire plus simplement

Réduire une expression, c'est l'écrire plus simplement en supprimant les parenthèses et en regroupant les termes semblables (les termes en x ensemble, les nombres ensemble).

Exemple

3x + 2 + 5x − 1 = (3x + 5x) + (2 − 1) = 8x + 1

🔗 Factoriser

Transformer une somme en produit

Factoriser, c'est le contraire de développer : on met en évidence le facteur commun.

ka + kb = k(a + b)
Exemples

6x + 9 = 3 × 2x + 3 × 3 = 3(2x + 3)

4a + 4b = 4(a + b)

📝 Récap express — tout en 4 points
  • Évaluer : remplacer les lettres par leur valeur, puis calculer.
  • Développer : k(a+b)=ka+kb ; +(a+b)=a+b ; −(a+b)=−a−b (le − change tous les signes).
  • Réduire : regrouper les termes semblables (ex : 3x + 5x = 8x).
  • Factoriser : ka+kb = k(a+b) (contraire de développer).
