🚀 Base martienne — Jour 4

La base martienne fonctionne désormais de manière stable.

Chaque jour, les mêmes opérations doivent être réalisées : relever les capteurs, vérifier les réserves d'eau et d'oxygène, contrôler la production d'énergie et enregistrer les nouvelles mesures.

Pour éviter de refaire ces tâches manuellement, les ingénieurs souhaitent créer un programme capable de les exécuter automatiquement.
