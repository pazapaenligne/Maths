Résous chaque équation puis valide-la. Écris la solution sous forme de fraction simplifiée ; un nombre décimal approché (2 décimales minimum) est aussi accepté.

1 3 − (−x − 1) = −3x + 4
Correction
On enlève la parenthèse : −(−x − 1) = x + 1, donc à gauche 3 + x + 1 = x + 4. L'équation devient x + 4 = −3x + 4. On regroupe : x + 3x = 4 − 4, soit 4x = 0, donc x = 0.
2 −2x + 6 = −8x + 6
Correction
On regroupe les x à gauche : −2x + 8x = 6 − 6, soit 6x = 0, donc x = 0.
3 7(−x − 7) = −6x − 3
Correction
On développe le membre de gauche : 7 × (−x) + 7 × (−7) = −7x − 49. L'équation devient −7x − 49 = −6x − 3. On regroupe : −7x + 6x = −3 + 49, soit −x = 46, donc x = −46.
4 7(−7x − 9) = −5x − 6
Correction
On développe : −49x − 63 = −5x − 6. On regroupe : −49x + 5x = −6 + 63, soit −44x = 57. On divise par −44 : x = −57/44.
5 8 − (−x + 7) = 2x − 8
Correction
On enlève la parenthèse : −(−x + 7) = x − 7, donc à gauche 8 + x − 7 = x + 1. L'équation devient x + 1 = 2x − 8. On regroupe : x − 2x = −8 − 1, soit −x = −9, donc x = 9.
6 −3x + 4 = 6x − 6
Correction
On regroupe les x à gauche : −3x − 6x = −6 − 4, soit −9x = −10. On divise par −9 : x = (−10) ÷ (−9) = 10/9.
7 9 − (8x + 6) = −x + 6
Correction
On enlève la parenthèse : 9 − 8x − 6 = −8x + 3. L'équation devient −8x + 3 = −x + 6. On regroupe : −8x + x = 6 − 3, soit −7x = 3. On divise par −7 : x = −3/7.
8 4x + 3 = x + 7
Correction
On regroupe les x à gauche et les nombres à droite : 4x − x = 7 − 3, soit 3x = 4. On divise par 3 : x = 4/3.
9 6(7x + 5) = 2x − 3
Correction
On développe : 42x + 30 = 2x − 3. On regroupe : 42x − 2x = −3 − 30, soit 40x = −33. On divise par 40 : x = −33/40.
