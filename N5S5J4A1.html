🏭 L’atelier de badges

Dans l’atelier, une fiche de fabrication doit être contrôlée avant le lancement de la production. Deux écritures mathématiques apparaissent de part et d’autre d’un signe.

Une valeur précise a été choisie pour la lettre utilisée dans les deux écritures. Le système de contrôle hésite à valider la fiche.

Fiche de contrôle n° 47
⏳ En attente
2k + 3
=
k + 8
k = 5

Tant que le contrôle n’est pas terminé, le badge ne peut pas être validé.

Les indices
  • Les deux écritures sont séparées par le signe =.
  • Une même valeur est utilisée dans les deux écritures.
  • Le système doit décider si la fiche est vraie ou fausse.
Comment vérifier si une égalité est vraie pour une valeur donnée ?
