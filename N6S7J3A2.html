🏆 Mission finale

La symétrie axiale

Le défi du jour

Les explorateurs rapportent une carte marine endommagée, conçue de manière parfaitement symétrique. Pour la restaurer, les cartographes doivent reconstruire la partie manquante comme si le parchemin était plié le long de son axe.

Comment construire le symétrique d'une figure par rapport à un axe sans modifier sa forme ni ses dimensions ?

1. La symétrie axiale

📚 Ce que je retiens

Deux figures sont symétriques par rapport à un axe lorsqu'elles se superposent parfaitement par pliage le long de cet axe.

Pour chaque point A et son symétrique A' :

  • le segment [AA'] est perpendiculaire à l'axe de symétrie ;
  • les deux points sont situés à la même distance de l'axe.

La symétrie axiale conserve : les longueurs ; les alignements ; les angles ; les aires.

✅ Exemple

Une figure est dessinée à gauche d'un axe de symétrie. Pour construire son symétrique :

  1. Je trace une droite perpendiculaire à l'axe passant par chaque sommet.
  2. Je reporte de l'autre côté de l'axe la même distance.
  3. Je place les points symétriques.
  4. Je relie les points dans le même ordre.
Résultat :
Même forme, mêmes dimensions.
🧩 Démarche

Sur quadrillage :

  1. Compter le nombre de carreaux entre un point et l'axe.
  2. Reporter le même nombre de carreaux de l'autre côté de l'axe.
  3. Recommencer pour chaque sommet.
  4. Relier les points dans le même ordre.

Sur papier blanc :

  1. Tracer la perpendiculaire à l'axe passant par le point.
  2. Mesurer la distance entre le point et l'axe.
  3. Reporter cette même distance de l'autre côté de l'axe à l'aide du compas.
  4. Relier les points symétriques dans le même ordre.

🎯 En résumé

Deux figures sont symétriques par rapport à un axe lorsqu'elles se superposent parfaitement par pliage le long de cet axe. Pour construire une symétrie axiale, chaque point doit être placé à la même distance de l'axe, de l'autre côté de celui-ci. La symétrie axiale conserve les longueurs, les alignements, les angles et les aires.
