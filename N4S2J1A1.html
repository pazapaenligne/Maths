🍯 MISSION NOUGAT PARFAIT

Le grand jour approche et le laboratoire de Colle & Sugar tourne à plein régime ! Pour réussir le nougat parfait, la température du sucre doit être surveillée de très près. Le thermomètre connecté affiche trois variations successives : une baisse de 12°C (ajout du miel froid), puis une hausse de 35°C (chauffage), puis une nouvelle chute de 8°C (incorporation des amandes). Calcule le bilan total de ces variations pour régler précisément le thermostat avant que la matière ne fige !

Additions de nombres relatifs en cascade — l'essentiel

1. Traduire une situation en variation signée :
• Hausse, augmentation, gain, bénéfice → signe +.
• Baisse, chute, diminution, perte, déficit → signe −.
Ex : « baisse de 12°C » → variation = −12.

2. Rappel : règles d'addition :
• Mêmes signes : on additionne les valeurs absolues et on garde le signe commun. Ex : (−5) + (−7) = −12.
• Signes opposés : on soustrait les valeurs absolues et on garde le signe du plus grand. Ex : (−8) + (+11) = +3.

3. Plusieurs additions en cascade : on traite les additions les unes après les autres, dans l'ordre où elles apparaissent.
Ex : (−5) + 8 + (−3) → (−5) + 8 = +3, puis +3 + (−3) = 0.

4. Méthode astucieuse : le regroupement : grâce à la commutativité de l'addition, on peut réorganiser les termes :
• Étape 1 : on additionne TOUS les positifs entre eux (somme positive).
• Étape 2 : on additionne TOUS les négatifs entre eux (somme négative).
• Étape 3 : on combine les deux sommes (signes opposés → soustraction des valeurs absolues).
Ex : (−5) + 8 + (−3) → positifs = +8 ; négatifs = −8 ; combinaison = 0.

5. Interpréter le résultat :
• Bilan positif → hausse globale.
• Bilan négatif → baisse globale.
• Bilan nul → les variations s'annulent (équilibre).

6. Vérification : pour s'assurer du résultat, on peut le recalculer avec l'autre méthode (cascade puis regroupement, ou inversement). Les deux doivent donner exactement le même nombre.
