Qu’est-ce qu’un algorithme ? · Centre de contrôle

🛰 CENTRE DE CONTRÔLE

Les ingénieurs du centre de contrôle doivent vérifier les systèmes de navigation, les panneaux solaires, les antennes et les communications avant le décollage du satellite. Pour que la préparation se déroule sans erreur, ces opérations doivent suivre une suite d’instructions organisée dans un ordre précis.

Qu’est-ce qu’un algorithme ? — l’essentiel

1. Définition :
Un algorithme est une suite finie d’instructions précises (non ambiguës), écrites dans un ordre précis afin de réaliser une tâche ou de résoudre un problème.

2. Exécution séquentielle :
Chaque instruction est exécutée l’une après l’autre, dans l’ordre où elle est écrite.

3. L’ordre compte :
Dans de nombreux algorithmes, modifier l’ordre des instructions change le résultat ou empêche l’exécution correcte de la tâche.

4. Exemple 1 — Préparer le satellite :
1. Alimenter les systèmes.
2. Vérifier les capteurs.
3. Déployer les panneaux solaires.
4. Activer les antennes.
Ces quatre étapes, dans cet ordre, constituent un algorithme.

5. Exemple 2 — Afficher un message :
• Allumer l’écran.
• Écrire « Satellite prêt ».
• Valider l’affichage.
L’ordre des actions est ici aussi indispensable : on ne peut pas écrire le message avant d’avoir allumé l’écran.
