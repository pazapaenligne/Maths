Factoriser avec un facteur commun

Quand le facteur commun est une expression entre parenthèses

📐 Le principe

La distributivité… à l'envers

Factoriser, c'est utiliser la distributivité dans l'autre sens :

ka + kb = k(a + b)

👉 Quand une expression est complexe, le facteur commun k n'est pas toujours un simple nombre ou une lettre : ça peut être une expression entre parenthèses, comme (2 + 3x).

🪜 La méthode

Étape par étape

  1. Identifier les termes de l'expression (séparés par des + ou des −).
  2. Repérer le facteur commun à tous ces termes.
  3. Mettre ce facteur en évidence devant une grande parenthèse.
  4. Réécrire ce qu'il reste à l'intérieur de la parenthèse pour chaque terme.
  5. Réduire l'expression à l'intérieur des parenthèses.
💡 Exemple pratique

Factoriser A = 3(2 + 3x) − (5 + 2x)(2 + 3x)

Les deux termes de A sont : 3(2 + 3x) et (5 + 2x)(2 + 3x).
Le facteur commun est (2 + 3x) : il apparaît dans les deux termes.
On met (2 + 3x) en facteur :
A = (2 + 3x) [3 − (5 + 2x)]
On réduit l'intérieur (attention au signe − devant la parenthèse !) :
3 − (5 + 2x) = 3 − 5 − 2x = −2 − 2x
A = (2 + 3x)(−2 − 2x)

⚠️ Piège du signe : dans le 2ᵉ terme, le « − » devant (5 + 2x) reste. Quand on réduit, ce moins change le signe de chaque terme : 3 − 5 − 2x (et non 3 − 5 + 2x).

✏️ D'autres exemples

Repère le facteur commun

(x+1)(x+2) + (x+1)(x+5) = (x+1)[(x+2)+(x+5)] = (x+1)(2x+7)
(2x−1)(x+3) − 4(2x−1) = (2x−1)[(x+3)−4] = (2x−1)(x−1)
5(x+2) + 3x(x+2) = (x+2)(5 + 3x)

💡 Le facteur commun saute aux yeux quand la même parenthèse revient dans chaque terme.

👉 Clique ici pour l'essentiel en résumé
  • Factoriser = distributivité à l'envers : ka + kb = k(a+b).
  • Le facteur commun peut être une parenthèse entière, ex : (2+3x).
  • 5 étapes : identifier les termes → repérer le facteur → le mettre devant → réécrire le reste → réduire.
  • On met le facteur commun devant une grande parenthèse (ou crochet).
  • ⚠️ Attention au signe − devant une parenthèse : il change tous les signes à l'intérieur.
  • On réduit toujours l'intérieur à la fin.
