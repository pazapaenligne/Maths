Gestion des commandes · fonction affine f(x) = 15x + 30

🥦 MISSION RECETTE SECRÈTE

La boulangerie « Pâte à Pouf » change son organisation. Le tableau de gestion affiche : « Détermine une règle de calcul fiable pour prévoir le nombre de gâteaux chaque jour ». Avec 30 gâteaux déjà prêts le matin et 15 par fournée, trouve la fonction affine f(x) = 15x + 30.

Fonction affine — l'essentiel

1. Définition : une fonction affine s'écrit f(x) = ax + b. Ici f(x) = 15x + 30.

2. Le coefficient a (part variable / pente) : ce qui s'ajoute à chaque fournée. Ici a = 15.

3. Le coefficient b (part fixe / ordonnée à l'origine) : la valeur pour x = 0. Ici b = f(0) = 30.

4. Résoudre une commande : f(x) = 105 → 15x + 30 = 105 → x = 5.

Différence avec le linéaire : si b = 0, c'est linéaire ; si b ≠ 0, c'est affine.
