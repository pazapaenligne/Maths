Les blocs paramétrés

▶ DÉFI RÉVISION 3E

Dans un laboratoire ultra-secret de Bugolie, les ingénieurs créent des programmes gigantesques. Mais les scripts deviennent trop longs ! Ils utilisent des blocs paramétrés pour automatiser. Problème : le pirate « Docteur Bug » a supprimé plusieurs paramètres essentiels. Un bloc paramétré, c'est du code réutilisable avec une valeur réglable. À toi de tout réparer !

Les blocs paramétrés

Un bloc personnalisé regroupe plusieurs instructions sous un seul nom, qu'on peut réutiliser autant de fois qu'on veut.

1. Pourquoi ? Pour éviter de réécrire le même code plusieurs fois.
Ex : un bloc « dessiner un carré » → on l'appelle quand on veut un carré.

2. Le paramètre est une valeur réglable qu'on donne au bloc.
Ex : « avancer de (50) » → 50 est le paramètre ; « avancer de (100) » avance plus loin.

3. Intérêt : un seul bloc, mille usages — il suffit de changer le paramètre.

Dans Scratch : menu « Mes blocs » → « Créer un bloc », puis on ajoute des paramètres.
