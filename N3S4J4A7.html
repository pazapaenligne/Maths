Que faire avec un triangle ?

Propriétés des triangles
On sait que le triangle est rectangle.
⬇️
On peut utiliser la formule du cosinus pour :
→ calculer un angle aigu
→ calculer une longueur
On peut calculer une longueur avec le théorème de Pythagore :
AB² = AC² + BC²
On nous demande si le triangle est rectangle.
⬇️
On vérifie si l'égalité de Pythagore est vraie ou fausse.
Vraie : d'après la réciproque, le triangle est rectangle ✅
Fausse : le triangle n'est pas rectangle ❌
📐 Le cosinus d'un angle

La formule à connaître

Dans un triangle rectangle, pour un angle aigu :

cos(angle) = côté adjacent / hypoténuse
cos(ACB) = BC / AC

📌 Le côté adjacent à un angle, c'est le côté qui « touche » cet angle (autre que l'hypoténuse).
Le côté opposé, c'est le côté en face de l'angle.

⭐ Bonus : SOH-CAH-TOA

Les 3 formules trigonométriques

En plus du cosinus, il existe le sinus et la tangente. Pour les retenir, on utilise le moyen mnémotechnique SOH-CAH-TOA :

SOH
Sinus
sin = opp / hyp
CAH
Cosinus
cos = adj / hyp
TOA
Tangente
tan = opp / adj

👉 Pour choisir la bonne formule, regarde les 2 côtés impliqués dans le problème :

  • opposé + hypoténuse → sinus
  • adjacent + hypoténuse → cosinus
  • opposé + adjacent → tangente
💡 Exemple

Calculer un angle avec le cosinus

Soit un triangle ABC rectangle en B, avec BC = 4 cm et AC = 5 cm. On veut calculer l'angle ACB.

  • BC est le côté adjacent à l'angle ACB.
  • AC est l'hypoténuse.
  • On utilise donc le cosinus (adjacent + hypoténuse) :
cos(ACB) = BC / AC = 4 / 5 = 0,8
ACB = arccos(0,8) ≈ 36,9°

💡 À la calculatrice : tape cos⁻¹(0,8) ou arccos(0,8). Vérifie que la calculatrice est en mode degrés (DEG).

👉 Clique ici pour l'essentiel en résumé
  • Si rectangle → on peut utiliser Pythagore (longueurs) et cosinus (angles/longueurs).
  • Pour prouver rectangle → on teste la réciproque de Pythagore.
  • SOH-CAH-TOA : sin=opp/hyp, cos=adj/hyp, tan=opp/adj.
  • Le côté adjacent à un angle = celui qui le touche (≠ hypoténuse).
  • Le côté opposé à un angle = celui en face de cet angle.
  • Calculatrice en mode DEG (degrés) pour les calculs trigo.
