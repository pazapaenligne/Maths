Développer et réduire · simple distributivité

▶ DÉFI RÉVISION 3E

Le parc écologique de GreenCity est en alerte : des centaines de déchets plastiques encerclent le lac. Les relevés des bénévoles sont codés en expressions. Ta mission : développer et réduire ces calculs pour débloquer l'opération de nettoyage avant le week-end.

Développer et réduire — l'essentiel

1. Développer : k(a + b) = k×a + k×b. Ex : 3(x + 4) = 3x + 12.

2. Réduire : regrouper les termes en x ensemble, les nombres ensemble. Ex : 4x + 3x + 2 = 7x + 2.

3. Développer puis réduire : 7(x + 2) + 3x = 7x + 14 + 3x = 10x + 14.

4. Calculer pour une valeur de x : remplacer x. Pour x = 6, 10x + 14 = 74.
