🔍 Défi du jour

Calculer des quantités pour préparer une livraison

📦 Zoo Zoologia — Jour 3

Le centre logistique prépare maintenant les livraisons destinées aux différents secteurs du zoo.

Certaines caisses sont déjà partiellement remplies. Les soigneurs doivent réunir le contenu de plusieurs caisses ou retirer une partie des réserves afin d'obtenir exactement les quantités demandées pour chaque livraison.

Les indices
  • Observe si les caisses doivent être réunies ou si une partie doit être retirée.
  • Compare les quantités présentes dans chaque caisse avant de les combiner.
  • Vérifie que le résultat correspond exactement à la quantité demandée pour la livraison.
