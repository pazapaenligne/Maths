Ouvrir le casier du musée

Le système s'ouvre uniquement si le résultat de l'expression est nul.

ÉQUATION DU SYSTÈME :
(x + 4)(x − 6) = 0

📋 Méthode en 5 étapes

1️⃣
Identifier les facteurs de l'équation.
2️⃣
Appliquer la règle du produit nul : si le produit est nul, au moins un facteur l'est.
3️⃣
Isoler chaque facteur séparément.
4️⃣
Résoudre chaque équation du type facteur = 0.
5️⃣
Vérifier les valeurs obtenues dans l'équation initiale.
⚠️ Points de blocage fréquents :
• Ne pas oublier que les deux facteurs sont considérés séparément.
• Ne pas confondre « produit nul » avec « somme nulle ».
• Toujours vérifier les solutions dans l'équation de départ.

🎯 Sélectionne les affirmations correctes

Groupe 1 / 2
Si le produit de deux facteurs est nul, au moins un des facteurs est nul.
Si le produit de deux facteurs est nul, les deux facteurs sont toujours nuls.
Si le produit de deux facteurs est nul, aucun facteur ne peut être nul.
Groupe 2 / 2
Les solutions de (x+4)(x−6)=0 sont x = −4 et x = 6.
La solution unique de (x+4)(x−6)=0 est x = 2.
Aucune solution réelle n'existe pour (x+4)(x−6)=0.
