Graphique d'une fonction affine — l'essentiel

1. Une droite (qui ne passe pas par l'origine) : f(x) = ax + b se représente par une droite. Elle coupe l'axe vertical en (0, b).

2. L'ordonnée à l'origine b : la valeur pour x = 0. Ici b = 30 (les gâteaux du matin).

3. La pente a : la montée par unité. Ici a = 15 (+15 gâteaux par fournée).

4. Lire une image : x = 3 → f(3) = 75.

5. Lire un antécédent : 90 gâteaux → x = 4.
