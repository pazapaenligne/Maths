🚩 BALISES DU SENTIER

Un violent orage d’été a déplacé les panneaux de signalisation sur le sentier des crêtes, créant un risque de chute pour les promeneurs. Pour sécuriser le parcours, tu dois distribuer de nouvelles balises aux équipes de patrouille. Tu disposes de deux lots : 5x balises rouges pour les zones de falaises et 15 balises jaunes pour les chemins glissants. Pour confier exactement le même équipement à chaque groupe de sauveteurs, tu dois regrouper ces expressions en trouvant le facteur commun maximal : 5x + 15. Trouve d’urgence sa forme factorisée pour diviser équitablement ton stock avant que les randonneurs ne s’égarent !

Factorisation simple — l'essentiel

1. Définition : factoriser, c'est transformer une somme en produit. C'est l'opération inverse du développement.
• Développer : 3(x+2) → 3x+6 (produit → somme).
• Factoriser : 3x+6 → 3(x+2) (somme → produit).

2. Le facteur commun : c'est un nombre, une lettre, ou une expression qu'on retrouve dans CHAQUE terme. Pour le repérer :
• Si tous les coefficients ont un diviseur commun > 1, c'est un facteur commun numérique. Le plus grand est le PGCD.
• Si une même lettre apparaît dans tous les termes, c'est aussi un facteur commun (en prenant l'exposant le plus petit).
Ex : pour 6x² + 9x, facteur commun = 3x (3 = PGCD(6,9), x présent partout avec exposant min = 1). On a donc 6x² + 9x = 3x(2x + 3).

3. Règle universelle : ka + kb = k(a + b). On peut généraliser : ka + kb + kc = k(a + b + c).

4. Méthode en 4 étapes :
1. Repérer le facteur commun (le plus grand possible).
2. Décomposer chaque terme pour faire apparaître ce facteur.
3. Sortir le facteur devant une parenthèse (la parenthèse contient ce qui reste de chaque terme).
4. Vérifier en développant : on doit retrouver l'expression initiale.

5. Pièges classiques :
• Oublier un terme dans la parenthèse : 5x + 15 ≠ 5(x). Il faut bien 5(x + 3).
• Ne pas factoriser au maximum : 4x + 8 = 2(2x + 4) est correct mais incomplet ! On peut encore factoriser : 4x + 8 = 4(x + 2). Toujours choisir le PLUS GRAND facteur commun.
• Oublier un signe : −3x − 12 = −3(x + 4), pas −3(x − 4).

6. Pourquoi factoriser ? En 4e, on utilise la factorisation pour : simplifier des expressions, résoudre certaines équations produit (a×b = 0), reconnaître des identités remarquables (qu'on verra dans la suite de la semaine !).
