Les nombres relatifs

Des nombres avec un signe (+ ou −), comment les comparer et les repérer sur une droite et dans le plan.

📖 Définitions

Positifs et négatifs

  • Les nombres positifs sont plus grands que 0. Ex : 3 ; 8,31…
  • Les nombres négatifs sont plus petits que 0. Ex : −2 ; −5,1…

Un nombre relatif est donc un nombre muni d’un signe : + ou −.

⚖️ Comparer

Quel est le plus petit ?

Deux nombres positifs

Le plus petit est celui qui est le plus proche de 0.
3 < 4

Deux nombres négatifs

Le plus petit est celui qui est le plus éloigné de 0.
−4 < −3
📏 Sur une droite graduée

Repérer un point

Une droite graduée possède une origine (O), un sens et une unité de longueur. La position d’un point s’appelle son abscisse.

× A abscisse −4  ·  × B abscisse 2  ·  O = origine  ·  unité = 0→1
🗺️ Dans le plan

Repérer avec des coordonnées

Dans le plan, un point est repéré par ses coordonnées (x ; y) : x sur l’axe des abscisses (horizontal), y sur l’axe des ordonnées (vertical).

C (2 ; 1) · D (−2 ; 0) · E (1 ; −1)

📝 Récap express — tout en 5 points
  • Un nombre relatif a un signe : positif (+) ou négatif (−).
  • Positifs > 0 (à droite de 0) · négatifs < 0 (à gauche de 0).
  • Deux positifs : le plus petit est le plus proche de 0 (3 < 4).
  • Deux négatifs : le plus petit est le plus éloigné de 0 (−4 < −3).
  • Dans le plan : un point = (abscisse ; ordonnée) = (x ; y).
