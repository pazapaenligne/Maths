🔄 VÉRIFICATION AUTOMATIQUE

Avant le décollage, le centre de contrôle doit vérifier 120 capteurs en leur faisant subir exactement la même série de tests. Plutôt que de répéter l’instruction 120 fois, les ingénieurs utilisent un mécanisme qui répète automatiquement la même action.

Utiliser les boucles — l’essentiel

1. Définition :
Une boucle permet de répéter automatiquement une suite d’instructions autant de fois que nécessaire sans les réécrire.

2. Quand l’utiliser :
Elle est utilisée lorsqu’une même action doit être exécutée plusieurs fois.

3. Exemple 1 — Vérifier 120 capteurs :
Au lieu d’écrire :
• Vérifier le capteur 1.
• Vérifier le capteur 2.
• Vérifier le capteur 3.
• …
• Vérifier le capteur 120.
on écrit :
Répéter 120 fois :
• Vérifier un capteur.

4. Exemple 2 — Faire clignoter un voyant 5 fois :
Répéter 5 fois :
• Allumer le voyant.
• Éteindre le voyant.
