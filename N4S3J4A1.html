Pour approvisionner simultanément ces deux points de secours majeurs, tu as préparé un grand stock de barres énergétiques et de gourdes filtrantes. Factorise cette expression au maximum pour simplifier la logistique avant que la canicule ne complique les rotations !

Factorisation par bloc commun — l'essentiel

1. Généralisation du facteur commun : le facteur commun n'est pas forcément un nombre seul. Ça peut être :
• Un nombre : 5x + 15 = 5(x+3).
• Une lettre : x² + 3x = x(x+3).
• Une parenthèse entière : (x+1)·a + (x+1)·b = (x+1)(a+b).
• Un produit nombre × lettre : 6x² + 9x = 3x(2x+3).

2. Repérer un bloc commun : on cherche une parenthèse (avec son contenu IDENTIQUE) présente dans tous les termes. La règle s'applique alors comme avant : k·a + k·b = k(a+b) avec k = la parenthèse commune.

3. Schéma type d'une factorisation par bloc :
• Expression de départ : (P)(A) + (P)(B) où P est le bloc commun.
• Étape 1 : on identifie P.
• Étape 2 : on écrit (P)[A + B] (on regroupe ce qui restait).
• Étape 3 : on simplifie A+B à l'intérieur.
• Étape 4 : on factorise encore si possible.

4. Penser à factoriser à fond : après une première factorisation, le résultat peut encore se factoriser. Toujours regarder :
• Y a-t-il un nouveau facteur commun numérique ?
• Y a-t-il un nouveau bloc qui apparaît ?
• Reconnaît-on une identité remarquable ?

5. Carrés : si on a deux parenthèses identiques multipliées entre elles, on peut écrire le carré : (a+b)(a+b) = (a+b)². Et k(a+b)(a+b) = k(a+b)².

6. Vérification : pour s'assurer que la forme factorisée est correcte, on la développe et on doit retomber sur l'expression de départ. Avec une calculatrice, on peut aussi essayer avec une valeur numérique de x (par exemple x = 1) dans les deux formes : le résultat doit être identique.

Factorisation par bloc commun — les compétences du jour
📝Bloc commun : le facteur commun peut être une parenthèse entière, pas seulement un nombre ou une lettre.
➗Sortir le bloc : on l’écrit devant, et on additionne les restes dans une grande parenthèse. (P)A + (P)B = (P)(A+B).
🧮Simplifier l’intérieur : enlever les parenthèses, regrouper les termes semblables.
⭐Factoriser à fond : après une factorisation, regarder s’il en reste une autre possible (nombre, bloc, identité).
À retenir : un facteur commun peut être une parenthèse entière. La règle ka + kb = k(a+b) reste valable avec k = (P). Après la première factorisation, on regarde toujours si on peut factoriser encore.
