Initiation à l'algorithmique

Le défi du jour

Le chantier de la gare est presque terminé. Les ingénieurs doivent programmer les déplacements d'un wagon d'inspection, qui doit suivre une suite d'instructions précises, toujours dans le bon ordre.

Comment suivre une suite d'instructions dans le bon ordre pour atteindre un objectif ?

1. Initiation à l'algorithmique

📚 Ce que je retiens

Un algorithme est une suite d'instructions :

  • précises ;
  • ordonnées ;
  • exécutées dans le bon ordre.

Chaque étape permet d'atteindre progressivement un objectif.

✅ Exemple

Programme :

  • avancer ;
  • tourner à droite ;
  • avancer ;
  • s'arrêter.
Résultat :
En exécutant chaque instruction dans l'ordre, le déplacement est correctement réalisé.
🧩 Démarche
  1. Lire la première instruction.
  2. L'exécuter.
  3. Passer à l'instruction suivante.
  4. Respecter l'ordre de toutes les étapes.
  5. Vérifier que l'objectif est atteint.
Figure — Le programme du wagon d'inspection
🎯 En résumé

Un algorithme est une suite d'instructions précises et ordonnées qui s'exécutent les unes après les autres afin d'atteindre un objectif ou d'automatiser une tâche.

Ce que tu maîtrises maintenant

► Algorithme : c'est une suite d'instructions précises et ordonnées ;

► Vérification : je m'assure que l'objectif est atteint après la dernière étape.
