Les identités remarquables

3 formules à connaître par cœur pour développer et factoriser plus vite

📐 Les 3 formules

À connaître par cœur

Pour tous les nombres a et b :

N°1
(a + b)² = a² + 2ab + b²
carré d'une somme
N°2
(a − b)² = a² − 2ab + b²
carré d'une différence
N°3
(a + b)(a − b) = a² − b²
produit d'une somme par une différence

⚠️ L'erreur à ne jamais faire : (a + b)² n'est PAS égal à a² + b² !
Il ne faut jamais oublier le terme du milieu : + 2ab (ou − 2ab).

💡 Développer

De gauche à droite

On utilise les formules pour développer rapidement, sans faire la double distributivité :

(x + 3)² = x² + 2×x×3 + 3² = x² + 6x + 9
(x − 5)² = x² − 2×x×5 + 5² = x² − 10x + 25
(x + 4)(x − 4) = x² − 4² = x² − 16

💡 Pour la 3ᵉ identité, le résultat n'a que 2 termes (le terme du milieu disparaît) : c'est très pratique !

🔄 Factoriser

De droite à gauche

On reconnaît une identité remarquable pour factoriser une expression :

x² + 6x + 9 = x² + 2×x×3 + 3² = (x + 3)²
x² − 16 = x² − 4² = (x + 4)(x − 4)
4x² − 9 = (2x)² − 3² = (2x + 3)(2x − 3)

💡 Une expression de la forme a² − b² (une différence de deux carrés) se factorise toujours en (a + b)(a − b).

👉 Clique ici pour l'essentiel en résumé
  • (a + b)² = a² + 2ab + b²
  • (a − b)² = a² − 2ab + b²
  • (a + b)(a − b) = a² − b²
  • ⚠️ Ne jamais oublier le terme du milieu 2ab.
  • Lues de gauche à droite → on développe.
  • Lues de droite à gauche → on factorise.
