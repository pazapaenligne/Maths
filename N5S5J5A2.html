Le défi du jour

Le programme de l’atelier transforme chaque nombre de départ en un réglage de badge. Les instructions restent toujours les mêmes, mais le nombre de départ change à chaque commande. Comment écrire ce programme de façon mathématique pour toutes les commandes ?

Quelle expression littérale représente le programme de l’atelier ?

1. Programmes de calcul et expressions littérales

Règle
Règle institutionnelle

Pour traduire un programme de calcul par une expression littérale, on remplace le nombre de départ par une lettre puis on écrit les opérations dans l’ordre où elles sont effectuées.

Définition
Un programme de calcul est une « machine » qui transforme un nombre en un résultat. Il est constitué d’une suite d’instructions effectuées dans un ordre précis.

Une expression littérale est une écriture mathématique contenant une ou plusieurs lettres représentant des nombres.
Traduire un programme en expression littérale
1Je remplace le nombre de départ par une lettre.
2J’écris les opérations dans le même ordre.
3J’obtiens une expression littérale.
4Je peux retrouver le programme en lisant l’expression.
Exemple — Programme A
Programme A : Multiplier par 5, puis ajouter 2.

Avec x comme nombre de départ :

x
→
5x
→
5x + 2

Vérification pour x = 99 :

5x + 2
=5 × 99 + 2
=495 + 2
=497
Le programme transforme 99 en 497.
Sens inverse — Lire une expression littérale

Pour l’expression 5x + 2, on retrouve le programme :

Programme reconstitué
1Choisir un nombre.
2Le multiplier par 5.
3Ajouter 2.
🎯 Je retiens : je sais traduire un programme de calcul par une expression littérale et retrouver un programme à partir d’une expression.
