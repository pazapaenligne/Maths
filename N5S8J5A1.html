Comprendre les structures conditionnelles

🚀 Base martienne — Jour 5

La base martienne est désormais entièrement automatisée.

Les programmes exécutent les relevés, mettent à jour les données et répètent les opérations nécessaires.

Cependant, certaines situations exigent désormais que le programme prenne une décision. Par exemple, selon les informations reçues par les capteurs, il peut être nécessaire d'allumer un système de secours, d'envoyer une alerte ou de poursuivre normalement les opérations.
