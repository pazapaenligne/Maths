Exercice 1 Développer et réduire

Développe et réduis l'expression suivante.

A = −6x + (−5x − 5)(−10x + 1) =
Développe d'abord le produit (−5x − 5)(−10x + 1) en appliquant la double distributivité (4 produits). Ajoute ensuite le terme −6x en regroupant les termes en x de même degré.
Exercice 2 Développer et réduire

Développe et réduis l'expression suivante.

A = −9(−2x − 5) + (−9)(8x − 4) =
Développe chaque parenthèse séparément avec k(a + b) = k×a + k×b. Attention : quand k est négatif, il change le signe de chaque terme. Regroupe ensuite les termes en x et les constantes.
Exercice 3 Identités remarquables

Développe et réduis les expressions suivantes.

A = (7z − 6)(7z + 6) =
B = (7a − 4)(7a + 4) =
C = (8y − 8)(8y + 8) =
Ces expressions sont de la forme (A − B)(A + B). Rappel de l'identité remarquable : (A − B)(A + B) = A² − B². Identifie A et B dans chaque expression, puis applique la formule.

Exercice 5
Yohaku multiplicatif

Trouve les expressions à placer dans les cases vides pour que les produits de chaque ligne et chaque colonne soient exacts.

Grille 1.
= 28x² + 98x + 70
= 45x² + 103x + 56
= 20x² + 78x + 70
= 63x² + 119x + 56
Grille 2.
= 18x² + 54x + 40
= 4x² + 24x + 32
= 6x² + 20x + 16
= 12x² + 68x + 80
Cherche des expressions de la forme ax + b telles que leur produit avec l'expression adjacent donne le produit indiqué. Essaie de factoriser les produits des colonnes et des lignes pour identifier les facteurs. Les cases d'une même grille sont toutes liées.
