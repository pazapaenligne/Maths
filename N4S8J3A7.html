Je relève le défi — Préparer les livraisons du zoo

Le centre logistique prépare maintenant les livraisons destinées aux différents secteurs du zoo. Certaines caisses sont déjà partiellement remplies. Les soigneurs doivent réunir le contenu de plusieurs caisses ou retirer une partie des réserves afin d'obtenir exactement les quantités demandées.

🎯 Ta mission

Ouvre l'exerciceur, puis sélectionne :

  • Opérations : Addition/Soustraction ;
  • la difficulté prévue par la professeure ;
  • Correction détaillée afin de comprendre tes erreurs.
👉 Accéder au défi
Cliquer ici

Pour écrire une fraction dans l'exerciceur, utilise la touche /. Par exemple, écris 3/4 pour représenter 34. L'outil accepte également certaines étapes intermédiaires.

🏁 Objectif de réussite

Résous correctement la série proposée par l'exerciceur afin de valider la préparation des commandes et permettre le départ des livraisons vers les différents secteurs du zoo.

Avant d'effectuer une addition ou une soustraction :
  1. vérifie les dénominateurs ;
  2. cherche un dénominateur commun lorsqu'ils sont différents ;
  3. transforme les fractions ;
  4. effectue l'opération sur les numérateurs ;
  5. simplifie le résultat lorsque c'est possible.

Livraison traitée

🎉 Mission accomplie !

Les quantités ont été correctement calculées et toutes les livraisons peuvent quitter le centre logistique.
