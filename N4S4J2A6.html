Le théorème de Thalès

📐 Configuration

Deux triangles emboîtés

Le théorème de Thalès s'utilise dans une configuration de deux triangles emboîtés : les points A, M, B sont alignés, ainsi que A, N, C. On compare le petit triangle AMN au grand triangle ABC.

📏 Théorème de Thalès

Calculer une longueur manquante
