🦊 TABLE D’ÉGOUTTAGE

Pour que le petit-lait s’écoule de tes faisselles de chèvre sans que les moules ne glissent, la table d’égouttage inclinée doit respecter un angle très précis. Les mesures du support triangulaire de la table sont prises : le plateau incliné (l’hypoténuse) mesure 150 cm et sa projection au sol (le côté adjacent) mesure 130 cm. Détermine la mesure de l’angle d’inclinaison (arrondi au degré près) pour régler d’urgence les vérins de sécurité !

Cosinus inverse (arccos) pour trouver un angle — l'essentiel

1. Le principe : quand on connaît la valeur du cosinus d'un angle (ou les deux longueurs qui permettent de la calculer), on utilise arccos pour retrouver l'angle. Notation : arccos(x) ou cos⁻¹(x).

2. Sur la calculatrice :
• Mode degrés : vérifier que « DEG » est affiché (sinon, basculer via le menu MODE).
• Touche arccos : généralement, on appuie sur SHIFT (ou 2nde) puis cos.
• On saisit la valeur du cosinus (entre 0 et 1 pour un angle aigu) puis [=].

3. Méthode pas-à-pas :
1. Repérer le triangle rectangle et l'angle aigu cherché.
2. Identifier les côtés : adjacent à l'angle, hypoténuse.
3. Calculer le rapport cos(angle) = adjacent / hypoténuse.
4. Appliquer arccos au résultat pour obtenir l'angle.
5. Arrondir selon la précision demandée.

4. Cosinus, sinus, tangente : laquelle utiliser ?
Selon les côtés connus :
• On connaît adjacent + hypoténuse → utiliser cos.
• On connaît opposé + hypoténuse → utiliser sin.
• On connaît opposé + adjacent → utiliser tan.
Et pour retrouver l'angle : arccos, arcsin, arctan respectivement.

5. Cas particuliers :
• arccos(1) = 0°
• arccos(0,866) ≈ 30° (car cos(30°) = √3/2 ≈ 0,866)
• arccos(0,707) ≈ 45°
• arccos(0,5) = 60°
• arccos(0) = 90°

6. Vérification : on peut vérifier le résultat en calculant cos(angle trouvé). On doit retomber sur le rapport de départ (aux arrondis près). Ex : si angle ≈ 30°, alors cos(30°) ≈ 0,866 ≈ 130/150 ✓.
