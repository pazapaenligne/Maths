La courbe d'une fonction affine

Dans un repère, la courbe représentative d'une fonction affine est une droite.

Vocabulaire : le nombre a est le coefficient directeur de la droite ; le nombre b est l'ordonnée à l'origine de la droite.
✍️ Exemple 1

f(x) = 3x − 2

Comme −2 est l'ordonnée à l'origine, la courbe représentative de f est une droite (d) passant par le point A(0 ; −2).

De plus, a = 3 est positif. Ainsi, lorsque x augmente de 1, f(x) augmente de 3. Donc la droite (d) passe aussi par (0+1 ; −2+3), soit B(1 ; 1).

✍️ Exemple 2

f(x) = −2x + 4

Comme 4 est l'ordonnée à l'origine, la courbe représentative de f est une droite (d) passant par le point A(0 ; 4).

De plus, a = −2 est négatif. Ainsi, lorsque x augmente de 1, f(x) diminue de 2. Donc la droite (d) passe aussi par (0+1 ; 4−2), soit B(1 ; 2).
