▲ Le calcul littéral, c'est manipuler des expressions avec des lettres.

📖 Les 4 actions

Ce qu'on peut faire avec une expression

1. Factoriser → transformer une somme en produit (mettre le facteur commun devant).

ka + kb = k(a + b)

2. Développer → transformer un produit en somme (enlever la parenthèse).

k(a + b) = ka + kb

3. Évaluer → remplacer la lettre par un nombre et calculer.

3x + 5 pour x = 2 → 3×2 + 5 = 11

4. Réduire → regrouper les termes semblables.

2x + 3x + 4 = 5x + 4

⚠️ Point clé

Le signe devant la parenthèse

C'est le piège le plus fréquent ! Tout dépend du signe juste avant la parenthèse :

+(a + b) = a + b   (rien ne change)
−(a + b) = −a − b   (tous les signes changent !)

⚠️ Un signe moins devant une parenthèse change le signe de chaque terme à l'intérieur. Exemple : −(x + 3) = −x − 3 (et non −x + 3 !).

👉 Clique ici pour l'essentiel en résumé
  • Factoriser : somme → produit (ka + kb = k(a+b)).
  • Développer : produit → somme (k(a+b) = ka + kb).
  • Évaluer : remplacer la lettre par un nombre, puis calculer.
  • Réduire : regrouper les termes semblables (les « x » ensemble).
  • +(a+b) = a+b : le plus ne change rien.
  • −(a+b) = −a−b : le moins change tous les signes.
