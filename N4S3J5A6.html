Les identités remarquables

Trois développements à connaître par cœur pour aller plus vite.

➕ Le carré d'une somme

(a + b)²

(a + b)² = a² + 2ab + b²

le carré du 1er, plus le double produit, plus le carré du 2e.

Exemple

(x + 3)² = x² + 2×x×3 + 3² = x² + 6x + 9

➖ Le carré d'une différence

(a − b)²

(a − b)² = a² − 2ab + b²

même chose, mais le double produit est négatif.

Exemple

(x − 5)² = x² − 2×x×5 + 5² = x² − 10x + 25

✖️ Le produit de la somme par la différence

(a + b)(a − b)

(a + b)(a − b) = a² − b²

le carré du 1er moins le carré du 2e (le terme du milieu disparaît).

Exemple

(x + 4)(x − 4) = x² − 4² = x² − 16

⚠️ Le piège classique : (a + b)² ≠ a² + b². Il ne faut jamais oublier le double produit 2ab !
