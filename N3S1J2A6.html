🧮 Équation produit-nul
▶ DÉFI MATHS 3ÈME
📌 RAPPEL — RÈGLE DU PRODUIT NUL
Un produit de plusieurs facteurs est égal à zéro si, et seulement si, l'un au moins de ses facteurs est nul.
A × B = 0 ⟺ A = 0 ou B = 0
💡 Méthode : on résout séparément chaque facteur égal à 0, puis on regroupe les solutions.
Défi unique
PRODUIT NUL
Résous l'équation suivante : (2x − 5)(x + 3) = 0 Quelle(s) valeur(s) de x satisfait(font) l'équation ? ⚠️ Plusieurs réponses possibles.
📝 Correction :
L'équation est sous la forme A × B = 0, donc A = 0 ou B = 0.

• 2x − 5 = 0  ⟹  2x = 5  ⟹  x = 52
• x + 3 = 0  ⟹  x = −3 Solutions : x = 52 ou x = −3
