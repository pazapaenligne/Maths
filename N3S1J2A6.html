◆ RAPPEL — LA RÈGLE DU PRODUIT NUL
Si A × B = 0, alors A = 0 ou B = 0.
Pour résoudre (ax + b)(cx + d) = 0, on résout séparément :
ax + b = 0 → x = −b/a cx + d = 0 → x = −d/c
Dans les exercices de cette mission, chaque équation possède deux solutions x₁ et x₂.
