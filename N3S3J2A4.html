Exercice 1 Double distributivité

Développe et réduis les expressions suivantes.

A = (7x + 9)(6x + 3) =
B = (5x + 7)(3x + 3) =
Rappel : (ax + b)(cx + d) = ax×cx + ax×d + b×cx + b×d.
Multiplie chaque terme du premier facteur par chaque terme du second (4 produits au total), puis regroupe les termes de même degré.
Exercice 2 Développer et réduire

Développe et réduis les expressions suivantes.

A = (−2 × 2)(−x + 7) =
B = −3 − (9x + 4)(5x − 9) =
Pour A : commence par calculer le produit numérique entre les deux parenthèses avant d'appliquer la distributivité.
Pour B : développe d'abord le produit (9x + 4)(5x − 9) avec la double distributivité. Attention ensuite au signe « − » devant la parenthèse : il change le signe de chaque terme.
Exercice 3 Réduire

Réduis les expressions suivantes, si cela est possible.

A = 8x − 2 − 4x + 11 =
B = −8x + 9x² =
Pour réduire : regroupe les termes de même nature (les termes en x ensemble, les termes en x² ensemble, les constantes ensemble).
Attention : on ne peut additionner que des termes de même degré. Un terme en x² et un terme en x ne peuvent pas se regrouper.
Exercice 4 Développer et réduire

Développe et réduis les expressions suivantes.

A = −7(3x + 7) + 7(x + 8) =
B = 4(−3x + 8) + (−9)(−9x + 2) =
Développe chaque parenthèse séparément en utilisant la distributivité simple : k(ax + b) = k×ax + k×b.
Attention aux signes : si k est négatif, le signe de chaque terme à l'intérieur change. Regroupe ensuite les termes en x et les constantes.
