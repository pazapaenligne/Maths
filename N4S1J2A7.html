Résoudre une équation du premier degré

Isoler l'inconnue pas à pas, et modéliser un problème par une équation du 1er degré.

📖 C'est quoi, une équation ?

Une égalité avec une inconnue

Une équation du 1er degré est une égalité qui contient un nombre inconnu, noté x. Elle peut s'écrire sous la forme :

a x + b = 0a et b : nombres connus · x : l'inconnue

Résoudre l'équation, c'est trouver la valeur de l'inconnue qui vérifie l'égalité. Si a ≠ 0, cette solution est unique.

🗝️ La règle d'or

Il faut isoler l'inconnue

Pour isoler x, on utilise les opérations inverses, en faisant la même chose des deux côtés de l'égalité :

① Ajouter / soustraire

x + b = c
x + b − b = c − b
x = c − b

On peut ajouter ou soustraire le même nombre des deux côtés.

② Multiplier / diviser (a ≠ 0)

a x = c
a xa = ca
x = ca

On peut multiplier ou diviser les deux côtés par un même nombre non nul (⚠️ on ne divise jamais par 0 !).

Exemple complet · 3x + 5 = 20

3x + 5 = 20
3x + 5 − 5 = 20 − 5  →  3x = 15
3x ÷ 3 = 15 ÷ 3  →  x = 5

La solution de l'équation est x = 5.

✅ Vérification : 3 × 5 + 5 = 20. L'égalité est vraie, x = 5 est bien la solution.

⚙️ Résolveur pas à pas — a x + b = c

Résous d'abord au brouillon, puis vérifie : entre les nombres a, b et c, l'outil isole x étape par étape.

🧩 Modéliser un problème

Les 4 étapes

1
Choisir l'inconnue : « soit x le nombre cherché ».
2
Mettre en équation : traduire l'énoncé avec x.
3
Résoudre l'équation en isolant x.
4
Répondre au problème par une phrase.
Exemple

« Je pense à un nombre, je le multiplie par 3, j'ajoute 5 et j'obtiens 20. Quel est ce nombre ? »

① Soit x le nombre pensé.  ② 3x + 5 = 20  ③ x = 5

④ Le nombre pensé est 5.

📝 Récap express — tout en 5 points
  • Équation du 1er degré : égalité de la forme ax + b = 0, x est l'inconnue.
  • Résoudre = trouver la valeur de x qui rend l'égalité vraie (unique si a ≠ 0).
  • On isole x avec les opérations inverses, en agissant des deux côtés.
  • x + b = c → x = c − b  ·  ax = c → x = c/a (a ≠ 0).
  • Problème : ① choisir l'inconnue ② mettre en équation ③ résoudre ④ répondre.
