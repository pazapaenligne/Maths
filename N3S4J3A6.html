Parallèles ou pas ?

La réciproque du théorème de Thalès pour prouver que deux droites sont parallèles

📖 Rappel

La configuration de Thalès

On est dans la configuration de Thalès quand on a 2 triangles emboîtés partageant un sommet A : M est sur [AB], N est sur [AC].

👉 La question du jour : connaissant AM, AB, AN et AC, les droites (MN) et (BC) sont-elles parallèles ?

🔄 La réciproque

Le théorème à utiliser

Dans la configuration de Thalès, SI on a l'égalité :

AM/AB = AN/AC

ALORS les droites (MN) et (BC) sont parallèles.

⚠️ Attention ! Si les deux quotients sont différents, alors les droites (MN) et (BC) NE sont PAS parallèles (c'est la contraposée).

🪜 La méthode

4 étapes pour conclure

  1. Repérer les longueurs AM, AB, AN, AC (attention aux sommets !).
  2. Calculer le 1er quotient : AM/AB.
  3. Calculer le 2ème quotient : AN/AC.
  4. Comparer les deux quotients :
    • ▸ égaux → (MN) // (BC) (réciproque de Thalès)
    • ▸ différents → (MN) et (BC) ne sont pas parallèles

💡 Astuce calcul : pour comparer deux fractions, simplifie-les ou utilise le produit en croix. AM/AB = AN/AC équivaut à AM × AC = AN × AB.

✅ Exemple 1 : parallèles

AM = 3, AB = 9, AN = 4, AC = 12

  1. On calcule AM/AB = 3/9 = 1/3.
  2. On calcule AN/AC = 4/12 = 1/3.
  3. Ainsi AM/AB = AN/AC = 1/3 : les quotients sont égaux.
  4. Donc, d'après la réciproque du théorème de Thalès, (MN) et (BC) sont parallèles.
✅ (MN) // (BC)
❌ Exemple 2 : pas parallèles

AM = 2, AB = 5, AN = 3, AC = 7

  1. On calcule AM/AB = 2/5 = 0,4.
  2. On calcule AN/AC = 3/7 ≈ 0,43.
  3. Ainsi AM/AB ≠ AN/AC : les quotients sont différents.
  4. Donc les droites (MN) et (BC) ne sont pas parallèles.
❌ (MN) et (BC) NE sont PAS parallèles
📊 Bilan visuel

Parallèles ou pas ?

✅ Quotients égaux → //

3/9 = 4/12 = 1/3
4/6 = 6/9 = 2/3
3/7 = 6/14 = 3/7

→ (MN) // (BC)

❌ Quotients différents → pas //

2/5 ≠ 3/7
5/8 ≠ 7/12
3/4 ≠ 4/5

→ (MN) et (BC) PAS //

  • Méthode : calculer AM/AB et AN/AC, puis comparer.
  • Quotients égaux → (MN) // (BC) ✅
  • Quotients différents → (MN) et (BC) PAS parallèles ❌

  • Toujours bien identifier les bons sommets (A en commun, M ↔ B, N ↔ C).
