💡 Double distributivité : (a + b)(c + d) = a×c + a×d + b×c + b×d.
👉 Exemple : (x + 3)(x + 5) = x² + 5x + 3x + 15 = x² + 8x + 15.
👉 Attention aux signes : (x − 2)(x + 4) = x² + 4x − 2x − 8 = x² + 2x − 8.
