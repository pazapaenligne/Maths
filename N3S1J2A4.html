Résous les équations produit nul (certaines solutions sont des fractions, ex : −7/9). Le dernier exercice est un problème type brevet : complète chaque étape puis valide.

1(5x + 10)(x − 2) = 0
Correction
5x + 10 = 0 → 5x = −10 → x = −2.
x − 2 = 0 → x = 2.
2(x + 10)(x + 9) = 0
Correction
x + 10 = 0 → x = −10.
x + 9 = 0 → x = −9.
3(2x + 2)(6x + 24) = 0
Correction
2x + 2 = 0 → 2x = −2 → x = −1.
6x + 24 = 0 → 6x = −24 → x = −4.
4(9x + 7)(5x + 9) = 0
Correction
9x + 7 = 0 → 9x = −7 → x = −7/9.
5x + 9 = 0 → 5x = −9 → x = −9/5. (Ici les solutions ne sont pas entières.)
5(x + 8)(x − 4) = 0
Correction
x + 8 = 0 → x = −8.
x − 4 = 0 → x = 4.
6Préparation DNB — produit nul et programme de calcul

D'après l'exercice 4 du brevet Antilles-Guyane 2024.

Programme de calcul
  • Choisir un nombre.
  • Mettre ce nombre au carré.
  • Soustraire le triple du nombre de départ.
  • Soustraire 4.

1. Si on choisit 5 comme nombre de départ, quel est le résultat du programme ?

2. On choisit x comme nombre de départ. Exprimer le résultat du programme en fonction de x.

3. Vérifier que ce résultat peut s'écrire sous forme d'un produit de deux facteurs (forme factorisée).

4. Déterminer les nombres à choisir au départ pour que le résultat du programme soit 0.

5. Programme Scratch : complète les lignes 4 et 6 pour qu'il corresponde au programme de calcul.

quand ⚑ est cliqué
demander Choisir un nombre et attendre
mettre x ▾ à réponse
mettre y ▾ à ? * ?
mettre z ▾ à 3 * x
mettre Résultat ▾ à ? − ? − 4
dire Résultat pendant 5 secondes

Indication : x est le nombre choisi, y son carré, z le triple de x. Écris la multiplication avec * ou ×.

Correction
1. Avec 5 : 5² − 3×5 − 4 = 25 − 15 − 4 = 6.
2. Avec x : x² − 3x − 4. Le résultat est x² − 3x − 4.
3. On cherche deux nombres dont la somme vaut −3 et le produit vaut −4 : ce sont +1 et −4. On développe (x + 1)(x − 4) = x² − 4x + x − 4 = x² − 3x − 4. Donc le résultat s'écrit (x + 1)(x − 4).
4. (x + 1)(x − 4) = 0 donne x + 1 = 0 ou x − 4 = 0, soit x = −1 ou x = 4.
5. Juliette doit compléter les lignes 4 et 6 :
mettre y ▾ à x * x
mettre Résultat ▾ à y − z − 4

Série terminée !
