Factoriser avec un facteur commun

Utiliser la distributivité « à l'envers », même quand le facteur commun est une parenthèse.

🔗 Principe

La distributivité à l'envers

Factoriser, c'est utiliser la distributivité à l'envers :

ka + kb = k(a + b)

Lorsqu'une expression est complexe, le facteur commun n'est pas toujours un simple nombre ou une lettre : il peut être une expression entre parenthèses.

🛠️ Méthode

Étape par étape

1Identifier les termes de l'expression (séparés par des + ou des −).
2Repérer le facteur commun à tous ces termes.
3Mettre ce facteur en évidence devant une grande parenthèse.
4Réécrire ce qu'il reste à l'intérieur de la parenthèse pour chaque terme.
5Réduire l'expression à l'intérieur des parenthèses.
✍️ Exemple résolu

A = 3(2 + 3x) − (5 + 2x)(2 + 3x)

Étapes
2Le facteur commun est (2 + 3x).il apparaît dans les deux termes
3A = (2 + 3x) [ 3 − (5 + 2x) ]on met (2 + 3x) en évidence
5A = (2 + 3x)(3 − 5 − 2x)le − devant (5 + 2x) change les signes
✓A = (2 + 3x)(−2 − 2x)résultat final factorisé
⚠️ Attention au signe : 3 − (5 + 2x) = 3 − 5 − 2x = −2 − 2x. Le − devant la parenthèse change le signe de chaque terme.

🎓 À toi de jouer

👉 Consigne : factorise l'expression B = (x + 1)(x − 3) + (x + 1)(2x + 5) en suivant la méthode, puis vérifie.
Solution
2Le facteur commun est (x + 1).
3B = (x + 1) [ (x − 3) + (2x + 5) ]
5B = (x + 1)(x − 3 + 2x + 5)
✓B = (x + 1)(3x + 2)on réduit : x + 2x = 3x et −3 + 5 = 2
📝 Récap express — la méthode en 5 étapes
  1. Identifier les termes (séparés par + ou −).
  2. Repérer le facteur commun (un nombre, une lettre ou une parenthèse).
  3. Mettre ce facteur en évidence devant une grande parenthèse.
  4. Réécrire ce qui reste à l'intérieur pour chaque terme.
  5. Réduire l'intérieur des parenthèses (attention au signe − !).
