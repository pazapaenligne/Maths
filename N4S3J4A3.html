Factoriser avec un facteur commun

Utiliser la distributivité « à l'envers », même quand le facteur commun est une parenthèse.

🔗 Principe

La distributivité à l'envers

Factoriser, c'est utiliser la distributivité à l'envers :

ka + kb = k(a + b)
🔎 Qu'est-ce que le facteur commun ?
C'est ce que l'on retrouve dans chacun des termes de l'expression. Ce peut être un nombre, une lettre, ou même une expression entre parenthèses.
🛠️ Méthode

Étape par étape

1Identifier les termes de l'expression (séparés par des + ou des −).
2Repérer le facteur commun — cherche ce qui apparaît dans tous les termes.
3Mettre ce facteur en évidence devant une grande parenthèse.
4Réécrire ce qu'il reste à l'intérieur de la parenthèse pour chaque terme.
5Réduire si possible l'expression à l'intérieur des parenthèses.
📗 Exemple simple

Factoriser quand le facteur commun est une parenthèse

L'expression A = 3(x + 2) + 5(x + 2) contient (x + 2) dans les deux termes.

Étapes
2Le facteur commun est (x + 2).il apparaît dans les deux termes
3A = (x + 2)(3 + 5)on met (x + 2) en évidence
5A = 8(x + 2)on réduit : 3 + 5 = 8
✍️ Exemple plus complexe

A = 3(2 + 3x) − (5 + 2x)(2 + 3x)

Étapes
1Deux termes : 3(2 + 3x) et (5 + 2x)(2 + 3x).
2Le facteur commun est (2 + 3x).il apparaît dans les deux termes
3A = (2 + 3x) [ 3 − (5 + 2x) ]on met (2 + 3x) en évidence
4A = (2 + 3x)(3 − 5 − 2x)le − devant (5 + 2x) change les signes
5A = (2 + 3x)(−2 − 2x)on réduit : 3 − 5 = −2
⚠️ Attention au signe : 3 − (5 + 2x) = 3 − 5 − 2x = −2 − 2x. Le − devant la parenthèse change le signe de chaque terme.

🎓 À toi de jouer

▸ Consigne : factorise l'expression B = (x + 1)(x − 3) + (x + 1)(2x + 5) en suivant la méthode, puis vérifie.
Solution
2Le facteur commun est (x + 1).
3B = (x + 1) [ (x − 3) + (2x + 5) ]
4B = (x + 1)(x − 3 + 2x + 5)on supprime les parenthèses intérieures
5B = (x + 1)(x + 2x − 3 + 5)on regroupe les termes semblables
✓B = (x + 1)(3x + 2)
📝 Récap express — la méthode en 5 étapes
  1. Identifier les termes (séparés par + ou −).
  2. Repérer le facteur commun — cherche ce qui apparaît dans tous les termes (nombre, lettre ou parenthèse).
  3. Mettre ce facteur en évidence devant une grande parenthèse.
  4. Réécrire ce qui reste à l'intérieur pour chaque terme.
  5. Réduire si possible (attention au signe − !)
