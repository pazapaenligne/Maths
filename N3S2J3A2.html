📋 L'essentiel à retenir

1.Une fonction affine s'écrit f(x) = ax + b ; sa représentation est une droite.
2.a = le coefficient directeur (la pente) ; b = l'ordonnée à l'origine (valeur pour x = 0).
3.Si b = 0 → fonction linéaire f(x) = ax : droite par l'origine, proportionnalité.
4.Si a = 0 → fonction constante f(x) = b : droite horizontale.
