1. Pour chaque décomposition, écrire le nombre décimal en chiffres correspondant.
Astuce : chaque facteur donne un chiffre à une position. ×10 → dizaines, ×1 → unités, ×0,1 → dixièmes, ×0,01 → centièmes, ×0,001 → millièmes, ×0,0001 → dix-millièmes. Place chaque chiffre à son rang, mets des 0 dans les rangs vides.
2. Décomposer les nombres en suivant l'exemple ci-dessous.
Exemple : 68,72 = (6×10) + (8×1) + (7×0,1) + (2×0,01)
Astuce : écris un produit par chiffre non nul. Ex : 378,5 = (3×100)+(7×10)+(8×1)+(5×0,1). Tu peux écrire les × comme « x » ou « * », et utiliser des espaces librement.
3. Donner l'écriture d'une fraction décimale de :
Astuce : compte les chiffres après la virgule pour choisir le dénominateur. 1 chiffre → /10, 2 chiffres → /100. Ex : 56,9 = 569/10 ; 235,01 = 23501/100. Écris ta réponse sous la forme numérateur/dénominateur.
4. Écrire en lettres les nombres suivants.
Astuce : la virgule se lit « virgule ». Ex : 56,9 → cinquante-six virgule neuf. Tu peux aussi dire la partie décimale par rang : 235,01 → deux cent trente-cinq virgule zéro un (ou « un centième »). On accepte plusieurs formulations.
