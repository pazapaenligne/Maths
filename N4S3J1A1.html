Calcul littéral : développer et réduire — l'essentiel

1. Vocabulaire :
• Une variable (ou lettre) représente un nombre inconnu ou variable.
• Un terme est un « morceau » d'expression. Ex : dans 3x + 7, les termes sont 3x et 7.
• Un coefficient est le nombre placé devant la lettre. Dans 5x, le coefficient est 5.
• Deux termes sont semblables s'ils ont la même partie littérale (même lettre, même exposant).

2. Réduire des termes semblables : on additionne (ou soustrait) leurs coefficients. La lettre reste identique.
Ex : 4x + 7x = 11x ; 9x − 2x = 7x ; 3x² + 5x² = 8x².
Attention : 4x + 7 ne se réduit pas ! (Termes non semblables : une lettre et un nombre seul.)

3. Distributivité simple : k(a + b) = k×a + k×b. On multiplie le facteur extérieur par CHAQUE terme de la parenthèse.
Ex : 3(x + 4) = 3x + 12 ; 5(2x − 3) = 10x − 15.

4. Distributivité avec un signe − : attention aux signes !
Ex : −2(x + 3) = −2x − 6 (le − entre dans la parenthèse) ; −(x − 4) = −x + 4.

5. Méthodologie : deux ordres possibles :
• Méthode A : réduire d'abord l'intérieur de la parenthèse si possible, puis multiplier. Ex : 2(3x + 2x) → 2 × 5x → 10x.
• Méthode B : distribuer d'abord, puis réduire les termes semblables. Ex : 2(3x + 2x) → 6x + 4x → 10x.
Les deux mènent au même résultat, choisis celle qui te paraît la plus claire !

6. Vérification numérique : pour vérifier qu'une simplification est juste, donne une valeur quelconque à x (par exemple x = 2) et calcule les deux expressions. Si elles donnent le même résultat, c'est bon signe.
