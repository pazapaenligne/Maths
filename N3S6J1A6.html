Se repérer

5 façons de donner la position d'un point : sur une droite, dans un plan, dans un pavé, sur une sphère, ou dans Scratch

🧭 Vue d'ensemble

Tout dépend de l'objet où on se trouve

Pour repérer un point, on a besoin de coordonnées. Leur nombre dépend de l'endroit :

SE REPÉRER
📏 Sur une droite 1 coord.
📐 Dans le plan 2 coord.
📦 Dans un pavé 3 coord.
🌍 Sur une sphère 2 coord.
🐱 Sur Scratch 2 coord.
📏 1 · Sur une droite

L'abscisse d'un point

Sur une droite graduée, un point est repéré par un seul nombre appelé son abscisse.

▲ A a pour abscisse 3 ; B a pour abscisse −2,5

  • Le point A a pour abscisse 3, on note A(3).
  • Le point B a pour abscisse −2,5, on note B(−2,5).
📐 2 · Dans le plan

Les coordonnées d'un point

Dans un plan (une feuille), un point a deux coordonnées notées dans l'ordre (abscisse ; ordonnée).

Point M(x ; y)
  • C(−3 ; 1,5)    D(0 ; −2)
  • E(1,5 ; −3)    F(3 ; 0)

⚠️ L'ordre compte ! On écrit toujours (abscisse ; ordonnée). C(−3 ; 1,5) ≠ C(1,5 ; −3).

📦 3 · Dans un pavé (3D)

Trois coordonnées

Dans l'espace à 3 dimensions, on a besoin de trois nombres : abscisse, ordonnée, et altitude.

Point P(x ; y ; z)

Exemple : P(4 ; 3 ; 4,2)

🌍 4 · Sur une sphère (la Terre)

Latitude et longitude

Sur la Terre, on utilise deux angles pour repérer un point :

  • Latitude : angle de 0° à 90°, qui détermine la position d'un cercle appelé parallèle, et la direction Nord ou Sud. Pour la Terre, le parallèle 0° est l'équateur.
  • Longitude : angle de 0° à 180°, qui détermine la position d'un demi-cercle appelé méridien, et la direction Est ou Ouest. Pour la Terre, le méridien 0° est le méridien de Greenwich.
Exemple : T(40°N ; 70°E)

▲ T est à 40° au Nord de l'équateur et 70° à l'Est de Greenwich

🐱 5 · Avec le logiciel Scratch

La scène de Scratch est un repère

Sur Scratch, on repère le lutin avec 2 coordonnées (x ; y). La scène mesure 480 × 360, avec le centre en (0 ; 0).

  • L'abscisse x va de −240 (gauche) à 240 (droite).
  • L'ordonnée y va de −180 (bas) à 180 (haut).
  • Le centre de la scène est l'origine (0 ; 0).
👉 Clique ici pour l'essentiel en résumé
  • Sur une droite : 1 coordonnée (l'abscisse). Ex : A(3).
  • Dans le plan : 2 coordonnées (abscisse ; ordonnée). Ex : C(−3 ; 1,5).
  • Dans un pavé (3D) : 3 coordonnées (x ; y ; z = abscisse ; ordonnée ; altitude).
  • Sur une sphère (Terre) : 2 angles (latitude N/S ; longitude E/O).
  • Sur Scratch : 2 coords (x de −240 à 240, y de −180 à 180), centre en (0 ; 0).
  • L'ordre des coordonnées compte toujours !
