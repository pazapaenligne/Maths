Déterminer les coordonnées d'un point dans un repère

Lis les coordonnées de chaque point dans le repère, puis complète. La première valeur est l'abscisse, la seconde l'ordonnée. Pense aux graduations intermédiaires.

Les coordonnées d'un point s'écrivent toujours sous la forme (abscisse ; ordonnée). Les graduations intermédiaires permettent de repérer des valeurs décimales ou fractionnaires. Attention aux nombres relatifs.
